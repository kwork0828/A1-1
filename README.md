# 나만의 프롬프트 관리 (Prompt Manager)

AI 프롬프트를 카테고리별로 저장하고 검색·관리할 수 있는 파이썬 콘솔 프로그램입니다.

## 1. 제작 배경

생성형 AI를 사용하다 보면 잘 작동했던 프롬프트를 메모장, 채팅 기록, 문서 등에 흩어 두게 되어
정작 다시 쓰려 할 때 찾지 못하는 일이 반복됩니다. 이 프로그램은 프롬프트를 한곳에 모아
용도별로 분류하고, 키워드로 찾고, 자주 쓰는 것은 즐겨찾기로 표시할 수 있도록 만들었습니다.

## 3. 실행 방법

```bash
git clone https://github.com/kwork0828/A1-1.git
cd A1-1
python prompt_manager.py
```

이미 파일을 내려받은 경우에는 해당 폴더에서 아래 명령만 실행하면 됩니다.

```bash

```

```bash
chcp 65001
```

## 4. 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력해 새 프롬프트를 등록합니다. |
| 2 | 프롬프트 목록 | 등록된 모든 프롬프트를 번호와 함께 출력합니다. |
| 3 | 카테고리별 조회 | 선택한 카테고리에 해당하는 프롬프트만 골라 보여 줍니다. |
| 4 | 프롬프트 검색 | 제목과 내용에서 키워드를 찾습니다. 대소문자를 구분하지 않습니다. |
| 5 | 프롬프트 상세 보기 | 번호를 선택해 제목·카테고리·즐겨찾기 여부·전체 내용을 확인합니다. |
| 6 | 즐겨찾기 관리 | 선택한 프롬프트의 즐겨찾기를 등록하거나 해제합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기로 등록된 프롬프트만 모아서 보여 줍니다. |
| 0 | 종료 | 프로그램을 종료합니다. |

## 5. 카테고리

텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타 여섯 가지를 기본으로 제공합니다.
카테고리 선택 화면에서 `0` 을 누르면 목록에 없는 이름을 직접 입력할 수도 있습니다.

## 6. 데이터 구조

프롬프트 한 건은 **딕셔너리**로 표현하고, 이 딕셔너리들을 **리스트**에 담아 관리합니다.

```python
prompts = [
    {
        "title": "브랜드 광고 카피 작성",
        "content": "당신은 15년 경력의 카피라이터입니다. ...",
        "category": "텍스트 생성",
        "favorite": True,
    },
    ...
]
```

| 키 | 자료형 | 의미 |
|---|---|---|
| title | 문자열 | 프롬프트 제목 |
| content | 문자열 | 프롬프트 본문 |
| category | 문자열 | 소속 카테고리 |
| favorite | 불리언 | 즐겨찾기 여부 |

리스트와 딕셔너리를 조합한 이유는 순서를 가진 목록 출력(번호 선택)과
항목별 속성 접근(제목·카테고리·즐겨찾기 수정)을 동시에 편하게 처리하기 위해서입니다.
데이터 처리는 다음과 같이 이루어집니다.

- 추가: `prompts.append(새 딕셔너리)`
- 목록·조회: `for i, prompt in enumerate(prompts, 1)` 로 순회
- 필터링: 리스트 컴프리헨션으로 카테고리 일치 항목 또는 키워드 포함 항목 추출
- 즐겨찾기: `prompts[index]["favorite"]` 값을 반전

데이터는 프로그램이 실행되는 동안 메모리에 유지되며, 종료하면 초기 상태로 돌아갑니다.
기본 프롬프트 4건이 미리 등록되어 있어 실행 직후 바로 모든 기능을 확인할 수 있습니다.

## 7. 함수 구성

| 함수 | 역할 |
|---|---|
| `print_line()` | 구분선 출력 |
| `print_prompt_line()` | 목록 한 줄을 동일한 형식으로 출력 |
| `input_nonempty()` | 빈 입력을 막고 값을 받을 때까지 반복 |
| `choose_category()` | 카테고리 선택 또는 직접 입력 처리 |
| `select_index()` | 번호 입력을 검증해 리스트 인덱스로 변환 |
| `show_menu()` | 메뉴 화면 출력 |
| `add_prompt()` | 프롬프트 추가 |
| `show_list()` | 전체 목록 출력 |
| `show_by_category()` | 카테고리별 조회 |
| `search_prompt()` | 키워드 검색 |
| `show_detail()` | 상세 정보 출력 |
| `toggle_favorite()` | 즐겨찾기 등록·해제 |
| `show_favorites()` | 즐겨찾기 목록 출력 |
| `main()` | 메뉴 반복 루프와 분기 처리 |

출력 형식과 입력 검증은 공통 함수로 분리해 각 기능에서 재사용했습니다.

## 8. 예외 처리

| 상황 | 처리 방식 |
|---|---|
| 메뉴에 없는 번호 입력 | 안내 메시지 출력 후 메뉴 재표시 |
| 제목·내용을 비워 둔 채 엔터 | "입력값이 비어 있습니다" 출력 후 재입력 요청 |
| 숫자가 아닌 값을 번호로 입력 | "숫자를 입력해 주세요" 출력 후 메뉴 복귀 |
| 범위를 벗어난 번호 입력 | "존재하지 않는 번호입니다" 출력 후 메뉴 복귀 |
| 조회·검색 결과가 없음 | 빈 화면 대신 안내 문구 출력 |
| 잘못된 카테고리 번호 | '기타'로 자동 지정 후 안내 |

## 9. 버전 관리 방식

- 기본 브랜치는 `main` 을 사용했습니다.
- 프롬프트 목록 기능은 `feature/prompt-list` 브랜치에서 개발한 뒤
  `git merge --no-ff` 로 병합해 브랜치 이력이 그래프에 남도록 했습니다.
- 커밋은 기능 단위로 나누고 아래 접두어를 사용했습니다.

| 접두어 | 용도 |
|---|---|
| feat | 새로운 기능 추가 |
| fix | 동작 오류·누락 보완 |
| docs | 문서 작성 및 수정 |
| refactor | 기능 변화 없는 구조 개선 |
| chore | 설정 파일·환경 관련 작업 |
| merge | 브랜치 병합 |

사용한 Git 명령은 `init`, `add`, `commit`, `push`, `clone`, `pull`, `checkout`, `merge` 입니다.
